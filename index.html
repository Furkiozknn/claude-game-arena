How the arena works

Arena nasıl işliyor

  1. One prompt per game in the same structure: World, Life, Game rules, Interaction, HUD, Extras, Performance (60 fps on a laptop iGPU) and Self-test.
  2. The model builds alone in its own folder, never sees the other games' code, and must verify its game in headless Chrome.
  3. Independent review: the bot is re-run, every screen and the phone layout are checked, the model ID is confirmed. Bugs go back to the same model for one fix round.
  4. Publishing: README, screenshots, clips, share metadata and GitHub Pages. The game code itself is the model's.
  1. Her oyuna tek prompt, hepsi aynı yapıda: Dünya, Yaşam, Oyun kuralları, Etkileşim, Arayüz, Ekstralar, Performans (dizüstü dahili ekran kartında 60 fps) ve Kendi kendini test.
  2. Model tek başına yapar, kendi klasöründe çalışır, diğer oyunların kodunu görmez ve oyununu görünmez Chrome'da kendisi test etmek zorundadır.
  3. Bağımsız inceleme: bot yeniden çalıştırılır, tüm ekranlar ve telefon görünümü kontrol edilir, model kimliği doğrulanır. Hatalar tek bir düzeltme turu için aynı modele geri gider.
  4. Yayın: README, ekran görüntüleri, videolar, paylaşım önizlemesi ve GitHub Pages. Oyunun kodu tamamen modelin kendisine ait.
